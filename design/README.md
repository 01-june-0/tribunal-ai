# 설계 시안

화면을 바꾸기 전에 모양과 동작을 정하려고 만든 보기용 페이지입니다. 브라우저로 `index.html`을 열면 됩니다.
제품 코드가 아니며, 안에 나오는 작업 · 숫자 · 실행 번호는 모두 예시 값입니다. 실제 구현은 시안과 달라진 부분이 있습니다
(달라진 점은 [docs/CONSOLE.md](../docs/CONSOLE.md)가 기준입니다).

| 폴더 | 정한 것 |
|---|---|
| `stage-mockups/`, `scene-variants/` | 한눈에 탭의 장면 모양 |
| `intro-roles-mockup/` | 역할 이름과 시작 연출 |
| `stage-approval-mockup/` | 작업 카드의 승인 · 멈춘 이유 · 변경 내용 보기 |
| `timeline-mockup/` | 통합 기록과 상세 패널 |
| `cloud-inside-mockup/` | 구름 줌인과 구름 속 화면 |
| `first-run-wizard-mockup/` | 처음 실행 도우미(비용 안내 → git → AI 설치 → 로그인 → 첫 작업), [PACKAGING.md](../docs/PACKAGING.md) 2단계 |
| `app-icon-mockup/` | 앱 아이콘 후보 다섯 가지(바로 가기 · 앱 창), [PACKAGING.md](../docs/PACKAGING.md) 3~4단계 |
