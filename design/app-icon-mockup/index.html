시안 · 앱 아이콘 · 배포 3~4단계

Tribunal AI 아이콘 후보 다섯 가지

바로 가기(macOS 응용 프로그램, Windows 시작 메뉴 · 바탕화면, Linux 앱 메뉴)와 앱 창에 쓸 그림입니다. 색은 콘솔과 같은 세 AI의 색(Claude 주황, Antigravity 파랑, Codex 청록)과 어두운 바탕입니다. 큰 그림 옆에 실제 크기(512 · 128 · 64 · 32 · 16px)와 Dock · 작업 표시줄 · 파일 목록에 놓인 모습을 함께 두었습니다. 16px에서도 알아볼 수 있는지가 가장 중요합니다.

고른 뒤에 하는 일

  • 고른 그림을 SVG 원본 하나로 저장하고, 거기서 macOS .icns, Windows .ico(16~256px), Linux .png를 만들어 패키지에 넣습니다.
  • 바로 가기에 연결: macOS 앱의 CFBundleIconFile, Windows .lnk의 아이콘 위치, Linux .desktop의 Icon=. 앱 창(pywebview)과 콘솔 탭의 아이콘(파비콘)에도 씁니다.
  • macOS Dock에 "Python"으로 보이는 문제도 같이 봅니다(아이콘을 앱에 붙이면 Dock 그림은 바뀌지만, 이름은 따로 손봐야 할 수 있음).
