# 콘솔

브라우저로 여는 화면입니다. `sh start-companion.sh`가 출력하는 주소(기본 `http://127.0.0.1:8081`)로 엽니다. 이 컴퓨터에서만
열리고, 탭은 두 개입니다.

| 탭 | 용도 |
|---|---|
| **한눈에** | 세 AI가 지금 무엇을 하는지, 작업이 어디까지 왔는지, 내가 결정할 것이 있는지 |
| **자세히** | 프로젝트 선택, 전체 대화, 실행 기록과 결과물 관리 |

위쪽 막대에는 프로젝트, 상태, 시계, 탭, **전체 화면**, **AI 설정**, 언어(한국어 / EN), **작업 정지**, **시스템 중지**가 있습니다.

## 1. 한눈에 탭

### 가운데 — 장면

구름 세 개가 세 역할이고, 가운데 핵이 Tribunal입니다. 색은 항상 같은 AI를 뜻합니다(Claude 주황, Codex 민트, Antigravity 파랑).
구름 아래 이름표에 역할, AI 이름, 지금 상태와 경과 시간, 오늘 호출 수와 토큰, 모델과 한도가 나옵니다. 이름표를 누르면 그 역할을
맡을 AI를 바꾸는 메뉴가 열립니다.

- **줌인** — AI 하나가 일하는 동안 카메라가 그 구름 쪽으로 다가가고 나머지 이름표는 흐려집니다. 테스트 단계에서는 핵 쪽으로
  조금 다가갑니다. 아무도 일하지 않으면 전체 구도로 돌아옵니다.
- **구름 속** — 구름을 누르면 안으로 들어갑니다. 그 AI가 지금 하고 있는 호출이 나오고, 쉬는 중이면 마지막 호출을 다시 보여 줍니다.
  - 가운데: 방금 한 일(쓴 도구와 대상, 한 말)이 초점 선에 크게 뜨고 지난 일은 위로 밀려나며 흐려집니다. 오류는 빨갛게 나옵니다.
  - 왼쪽: 받은 지시 — 목표, 단계, 바꿀 수 있는 파일, 완료 기준.
  - 오른쪽: 경과 시간, 모델, 도구 호출과 오류 수, 마지막 활동 뒤 지난 시간, 많이 쓴 도구, 토큰.
  - 아래: 호출 전체의 흐름을 시간 눈금으로.
- **핵 속** — 핵을 누르면 Tribunal이 실행한 가장 최근 테스트가 나옵니다. 테스트가 도는 동안에는 출력이 나오는 대로 보이고
  (pytest의 점이 하나씩 늘어남), 끝나면 결과로 바뀝니다. 명령, 통과 · 실패 수, 종료 코드, 시작 전 기준, 그때 바뀌어 있던 파일이
  함께 나옵니다.
- 나가기: Esc 또는 "← 밖으로". 줌인 중에는 무대 안에 온전히 보이는 구름만 누를 수 있습니다.

아래쪽 흐름 줄(`설계 → 제작 → 테스트 → 감리 → 판단`)은 지금 단계를 표시합니다.

### 왼쪽 — 지금과 작업

- **지금**: 한 문장으로 된 현재 상황, 경과 시간, 예상 남은 시간(과거 같은 종류 호출의 중앙값으로 낸 추정), 호출 안에서 방금 한 일.
- **작업 카드**: 목표, 단계 칩, 테스트 결과, 그리고 상황에 따라 아래 상자 중 하나.

| 상황 | 카드에 나오는 것 |
|---|---|
| 승인이 필요함 | 이유와 대상 파일, **승인하고 계속** / **거절**, 이 단계의 지시서 |
| 승인 후 다시 시작 중 | 안내만 |
| 승인으로 풀 수 없는 멈춤 | 멈춘 이유, 단계별 결과 |
| 끝내지 못하고 멈춤 · 작업 정지로 멈춤 | 멈춘 이유, **다시 계획해서 시도** 또는 **이어서 시도**. 통과한 단계가 없으면 **작업 사본 지우기**도 |
| 내가 거절함 | "거절한 작업" — 경고색 없이 닫힌 상태로 |
| 통과한 결과물이 있음 | **변경 내용 보기** → 파일별 변경을 읽고 **원본에 적용** 또는 **폐기** |

여러 단계로 이어진 작업은 한 번에 적용됩니다. 변경 내용 보기에는 모든 단계가 원본에 쓸 파일이 함께 나오고, "N개 단계의 변경"
이라고 표시됩니다. 내가 그 사이 고쳐서 충돌하는 파일과 AI가 지운 파일은 적용되지 않으므로 목록에 없고, 개수만 따로 나옵니다.

원본에 적용하면 그 작업의 작업 사본과 실행 브랜치는 자동으로 지워집니다. 폐기할 때도 같습니다. 충돌한 파일을 건너뛰고 적용한
경우에만 작업 사본이 남습니다(AI가 만든 그 파일을 직접 가져다 쓸 수 있도록). 다 쓴 뒤에는 결과물 카드의 **작업 사본 지우기**로
정리합니다. **작업 사본 지우기**로 정리한 작업은 이어서 할 수
없습니다.

적용한 뒤에는 원본에서 테스트를 다시 돌립니다. 통과하지 못하면 원본을 적용 전으로 되돌리고 그 사실을 알려 줍니다. 충돌한
파일을 건너뛴 탓에 나머지만으로는 동작하지 않을 때 이렇게 됩니다.

적용이 충돌로 보류되면, 다시 누를 때 충돌한 파일만 건너뛰고 나머지를 적용할지 묻습니다.

### 오른쪽 — 작업량과 기록

- **AI별 작업량**: 이번 작업 / 오늘 / 전체 기준의 호출 수, CLI 시간, 토큰. `~`는 글자 수로 추정한 값입니다.
- **기록**: AI 호출, Tribunal이 직접 한 일, 내 결정을 시간순 한 줄기로 합친 목록입니다. 작업별로 묶이고
  `전체 / AI 호출 / 확인 · 오류`로 걸러 볼 수 있습니다.

| 줄 | 예 |
|---|---|
| AI 호출 | `Codex 코드를 만들었습니다 · 파일 2개 변경 · 11초 · 5,371 토큰` |
| Tribunal | `테스트를 직접 실행했습니다 · 2회차 · 테스트 3개 중 1개 실패`, `시작 전에 승인을 요청했습니다`, `통과로 마쳤습니다` |
| 나 | `승인했습니다`, `거절했습니다`, `결과물을 원본에 적용했습니다`, `결과물을 폐기했습니다` |

줄을 누르면 **상세 패널**이 열립니다.

| 줄 | 상세에 나오는 것 |
|---|---|
| AI 호출 | 상태와 종료 코드, 시작 · 끝, 걸린 시간, 모델 · 추론 강도, 입력 · 출력 토큰, 그 호출이 낸 결과(지시서 / 바뀐 파일 / 감리 판정과 지적 / 판단과 근거), 호출 안에서 한 일. 제작 호출에는 작업 사본에 함께 들어간 추적 안 된 파일 목록 |
| 테스트 실행 | 회차, 명령, 통과 · 실패 수, 종료 코드, 시작 전 기준, 출력 끝부분, 그때 바뀌어 있던 파일 |
| 멈춤 · 마침 | 결과, 걸린 시간, AI 호출 수와 토큰, 자동 수정 횟수, 이유 원문, 마칠 때의 검사, 바뀐 파일, 작업 사본에 함께 들어간 추적 안 된 파일 |
| 내 결정 | 무엇을 언제 결정했는지, 그 뒤에 일어난 일, 요청 이유 원문, 승인 범위나 적용한 파일 |

패널 아래에는 값의 출처(어느 기록인지)가 적혀 있습니다. 기록에 없는 값은 "기록 없음"으로 나오고 추정해서 채우지 않습니다.

### 아래 — 대화

ARCHITECT에게 지시를 보내는 입력창입니다. 접힌 줄을 누르면 대화 기록이 펼쳐집니다. 시스템이 남긴 기록 줄은 문장으로 바꿔
보여 주고, 마우스를 올리면 원문이 보입니다.

## 2. 자세히 탭

한 화면에 들어오도록 배치되어 있습니다(창이 아주 작으면 페이지가 스크롤됩니다).

- **위**: 시스템 상태, 현재 작업과 다음 행동, 처리할 항목 알림.
- **왼쪽**: 프로젝트(폴더 선택 또는 경로 직접 입력), AI 복구 상태, 결과물 목록, 승인 대기.
- **가운데**: ARCHITECT와의 전체 대화.
- **오른쪽**: 현재 실행의 단계 진행, 승인 카드, 결과물 상세(바뀐 파일, 테스트 근거, 적용 · 폐기 · 작업 사본 열기).
- **아래**: AI 카드 세 장 — 상태, 맡은 역할, "상세보기"에 실제 사용량과 요금제.

## 3. AI 설정

위쪽 막대의 **AI 설정**에서 엽니다.

- CLI별 **모델**과 **추론 강도**. 바꾼 설정은 다음 호출부터 적용됩니다.
- **한도**: 5시간 · 주간 사용률과 요금제. 각 CLI에게 직접 물어 얻은 값이고, 조회 주기를 정할 수 있습니다. 한도가 임박하면 경고가
  뜹니다.
- **계정**: 어느 계정으로 로그인되어 있는지. 이메일은 가려서 보여 주고, 누르면 20초 동안만 전체를 보여 주며 저장하지 않습니다.
  로그인 · 계정 변경 · 로그아웃은 터미널 창을 열어 각 CLI의 명령으로 합니다. Tribunal은 토큰이나 비밀번호를 읽지 않습니다.

## 4. 정지

| 버튼 | 하는 일 |
|---|---|
| **작업 정지** | 돌고 있는 CLI를 즉시 끝내고 작업을 정지 상태로 고정. 그 뒤로는 새 호출 · 다음 단계 계획 · 적용을 하지 않고, 콘솔을 다시 켜도 이어 하지 않음. 작업 카드의 **이어서 시도**로 멈춘 자리에서 이어 감 |
| **시스템 중지** | 콘솔 서버를 끔. 기록과 작업 사본은 그대로 남고, 진행 중이던 작업은 다시 켜면 이어 함 |

채팅에 "중단", "멈춰", "그만", "stop"처럼 멈추라는 뜻의 짧은 말을 보내면 ARCHITECT에게 전달하지 않고 작업 정지로 처리합니다.

## 5. 그 밖에

- **전체 화면**: 입력창과 버튼을 숨기고 장면만 봅니다(단축키 B). 보기 전용이라 구름과 이름표를 누를 수 없습니다.
- **언어**: 한국어와 영어, 두 탭 모두. 사람과 AI가 쓴 글(대화, 목표, 파일 내용)과 대화의 시스템 기록 원문은 번역하지 않습니다.
- **창이 보이지 않을 때**는 서버에 아무것도 묻지 않고, 다시 보이는 순간 한꺼번에 갱신합니다.
- **데모 콘솔**: `python scripts/demo_console.py`는 지어낸 작업으로 채운 읽기 전용 콘솔을 다른 포트에 띄웁니다.

## 6. 한계

- 화면은 주기적으로 갱신합니다(작업 상태 3초, 호출 안의 일 2초, 실행 중인 테스트 0.7초). 아주 짧은 호출이나 1초 안에 끝나는
  테스트는 진행 모습 없이 결과만 보입니다.
- 호출 안에서 한 일은 각 CLI가 남기는 세션 기록을 읽어 보여 줍니다. 도구 이름과 대상, 오류 여부는 나오지만 명령의 출력 내용과
  명령별 걸린 시간은 그 기록에 없습니다.
- 모델 · 추론 강도는 이 기능이 생긴 뒤의 호출부터 기록됩니다.
- Codex는 입력과 출력을 나누지 않고 토큰 합계만 알려 줍니다.
- 낮은 창에서는 기록이 한 번에 서너 줄만 보이고 나머지는 스크롤합니다.
